Public Records Dashboard

The public-records material this project publishes, in one place
Sweep {{ human_utc(snapshot.generated_utc) if snapshot.generated_utc else 'pending' }}

JCStream republishes public records kept by the Hamilton County Sheriff’s Office. A requester’s right to inspect and copy those records from the public office is governed by R.C. 149.43. This page collects what the project itself publishes about those records: the open data feeds, the access-interruption evidence, and the transparency scorecard.

Records and feeds

Open data feeds Every JSON feed this site is built from: the current roster snapshot, the changelog, and the supplemental open-data pulls, each with its own refresh stamp. Access-interruption evidence log Timestamped, tamper-evident record of blocked or empty responses from the HCSO public inmate-search portal, logged per retrieval cycle. Transparency scorecard Tallies computed from the evidence log (block counts, streaks, cumulative denied hours), plus a JSON mirror of the metrics.

Requesting records yourself

To request public records directly from the agency, use the Sheriff’s Office public records request page or email publicrecords@hcso.org.

This dashboard lists only material the project publishes. It is not a records repository and does not hold correspondence with the agency.
