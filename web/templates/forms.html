Court Forms

Common Pleas, current generation rev. 4-24-26

The forms the court currently accepts, plus prior generations and related forms. Always file the current generation.

What do you need to file?

Pleading guilty or no contest in Common Pleas: use the current plea forms.

Giving up a jury trial: the current Waiver of Trial by Jury.

Cannot afford court costs: the current Affidavit of Indigency.

Filing a discovery plan: see Discovery below.

Scheduling a case or applying to mediate: see Scheduling and mediation below.

Looking for an older version of a plea form: see Archived generations.
