**PERF-01, open:** the full-charge search index improves completeness but increases compressed index size about 3.1 times and cold suggestion completion about 77% in this small lab sample. Homepage improvement is not a blanket performance pass. Archive filter timing also increased about 10% in this sample. These observations require representative-device/network measurement and an explicit performance decision before Gate C can pass. The timing script measures automation-observed completion, not field INP/FID, and three runs do not establish statistical significance. No performance threshold or risk acceptance was invented.
